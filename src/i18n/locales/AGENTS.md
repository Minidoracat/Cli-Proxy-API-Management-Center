# locales

## Purpose
Translation files for each supported language. Flat JSON key-value structure used by i18next.

## Key Files

| File | Description |
|------|-------------|
| `en.json` | English translations (primary/fallback) |
| `zh-CN.json` | Simplified Chinese translations |
| `ru.json` | Russian translations |

## For AI Agents

### Working In This Directory
- Always update **all three** locale files when adding/modifying keys
- Keys should be descriptive and dot-namespaced (e.g., `dashboard.title`)
- English (`en.json`) is the fallback language
